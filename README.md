# TypeCraft

TypeCraft 是一款面向 Notion、Obsidian 等现代编辑器的真人模拟打字工具。它不是简单粘贴文本，而是按可配置的节奏逐字输入，并结合 Markdown 结构识别、编辑器自动补全适配和键盘脚本，把文本尽量自然地“打”进目标窗口。

## 核心特性

- 真实输入模拟
  - 支持最小/最大字符延迟、随机抖动、标点停顿、句末停顿和随机长停顿。
  - 支持模拟输入错误并自动退格修正。
  - macOS 下会针对双空格变句号的问题增加空格保护延迟。
- Markdown 结构识别
  - 自动识别标题、列表、引用、分隔线、表格和代码块。
  - 可根据目标编辑器是否会自动续写列表/引用前缀，决定是否跳过这些符号。
  - 支持 Markdown 表格转真实表格输入模式。
- 编辑器行为适配
  - 支持智能跳过编辑器自动补全生成的括号、引号、大括号等闭合符号。
  - 支持通过键盘脚本控制表格单元格跳转、行跳转和退出行为。
- 两种代码块模式
  - `markdown`：按原样输入代码块开始行和结束行，适合 Obsidian 这类纯 Markdown 编辑器。
  - `block_editor`：用 ````` 触发块编辑器的代码块，再通过退出脚本离开代码块，适合 Notion 这类块式编辑器。

## 环境要求

- Python 3.8+
- `pynput`

安装依赖：

```bash
pip install pynput
```

## 运行方式

```bash
python main.py
```

## 使用流程

1. 在“输入文本”页粘贴或导入要输入的内容。
2. 在“打字设置”页调整速度、停顿、错误模拟和系统类型。
3. 在“Markdown/表格”页配置目标编辑器的自动续写行为、表格脚本和代码块模式。
4. 点击“开始执行”，然后在倒计时结束前切换到目标编辑器窗口。

## 关键配置说明

### 表格模式

- 开启“Markdown 表格转真实表格模式”后，程序会把 `| a | b |` 这类表格行按真实表格输入。
- “跳过 Markdown 分隔线 (`| --- |`)”决定是否忽略表头和正文之间的分隔线。
- 你可以分别配置：
  - 单元格间移动脚本
  - 行之间移动脚本
  - 表格结束退出脚本

### 代码块模式

- `markdown`
  - 原样输入 ````` 开始行。
  - 代码内容按普通文本逐字输入。
  - 原样输入 ````` 结束行。
- `block_editor`
  - 先输入 ````` 触发目标编辑器的代码块。
  - 如果开始行带语言标记，例如 ` ```python `，会继续输入 `python`。
  - 结束时执行“退出代码块脚本”；如果脚本留空，则回退为原样输入结束 fence。

## 当前行为约束

- 运行中或暂停中再次点击“开始执行”会被忽略，避免重复启动多个输入线程。
- 任务结束时会区分“输入完成”和“已停止”两种状态。
- 当前仓库没有自动化测试，主要依赖静态校验和手动联调。

## 开发提示

- 打字节奏和符号处理主要在 `core/handlers/character_handler.py`。
- 代码块、表格和整体状态机在 `core/engine.py`。
- Markdown 行类型识别和补全符号解析在 `core/processor.py`。
- UI 配置项在 `ui/app.py` 和 `ui/tabs/` 下。
